# Hirecore
Ejercicio 2 de Arquitectura de Software

Acá estamos haciendo una prueba!!!

## Cómo ejecutarlo

El programa corre en el navegador con una interfaz sencilla (botones y formularios).

```bash
npm install    # instala TypeScript como dependencia de desarrollo
npm run build  # compila los .ts a JS en dist/
```

Luego abre `index.html` en el navegador (doble clic o "Open with Live Server"). No hace falta abrir DevTools: el menú, los formularios y el registro de mensajes están en la propia página.
